Я б тільки розділив твою ідею на два етапи.

### 1. Спочатку — геометрія променя

Нехай гравець перебуває в точці \\((x_0,y_0)\\), а промінь має напрямок \\(\alpha\\).

Тоді його напрямний вектор:

\\[ d_x=\cos\alpha,\qquad d_y=\sin\alpha \\]

Будь-яка точка променя описується так:

\\[ x(t)=x_0+t\cdot d_x \\]

\\[ y(t)=y_0+t\cdot d_y \\]

Тепер перетин із вертикальною межею \\(x=X\\):

\\[ t_x=\frac{X-x_0}{d_x} \\]

А з горизонтальною межею \\(y=Y\\):

\\[ t_y=\frac{Y-y_0}{d_y} \\]

Тобто тригонометрію ти справді обчислюєш один раз на промінь, а далі працюєш із простими арифметичними операціями.

### 2. Потім — обхід клітинок

Твоя ідея починати з клітинки гравця правильна.

Знаки компонентів напрямного вектора визначають, у який бік рухатися:

| Компонента | Напрямок |
| ---------- | -------- |
| `dx > 0`   | вправо   |
| `dx < 0`   | вліво    |
| `dy > 0`   | вниз     |
| `dy < 0`   | вгору    |

Оскільки Canvas має вісь Y, спрямовану вниз, це важливо врахувати.

Тут є цікавий момент: на кожному кроці можна визначати відстань до найближчої вертикальної та горизонтальної межі. Менша відстань покаже, яку межу промінь перетне наступною.

Так ти поступово пройдеш крізь сітку, доки не зустрінеш стіну.

Це, власне, і є основа DDA, але поки навіть не обов'язково користуватися цією назвою.

### 3. Щодо текстурних координат

Тут теж правильно мислиш.

Якщо перетин відбувся на вертикальній стіні, тебе цікавить залишок від ділення координати Y точки перетину на розмір клітинки:

\\[ textureX = y\_{\text{intersection}} \bmod cellSize \\]

Для горизонтальної стіни аналогічно використовуватимеш X.

Тільки не забудь нормалізувати результат до діапазону від 0 до 1, коли перейдеш від піксельних координат до текстурних.

І найважливіше: я б поки не намагався будувати оптимальний алгоритм.

Ти маєш чудовий експериментальний майданчик:

- невелика обмежена решітка;
- відомі координати всіх стін;
- прямі кути;
- постійний розмір клітинки;
- контрольована геометрія.

Спочатку зроби один промінь. Намалюй його на двовимірній схемі, покажи всі точки перетину різними кольорами. Перевір горизонтальний, вертикальний і діагональний напрямки.

Коли один промінь запрацює правильно, решта буде вже питанням циклу.
